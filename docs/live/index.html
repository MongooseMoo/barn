What the words mean

  • Bug found: a lane saved an input that makes Barn fail, and opened a new issue for it. This is the machine working. Each new issue starts an automatic repair run, which leaves a PR for review.
  • Repeat: a lane hit a bug that already has an issue (still open, or fixed after the commit this cycle tested). It is added to that issue, not counted as new.
  • Machine problem: the machine itself failed, not Barn: a run killed without a saved input (for example out of memory), a setup or upload step failing, a lost runner, a cancelled or timed-out job.
  • No report found: a lane went red but no issue was opened or added to while it ran, as far as this page can see. Open the job to find out why.
  • Healthy cycle: every lane ran its full time and kept its evidence, whatever it found. The "Accept discovery cycle" job decides this.

This page reads GitHub's public API from your browser, with no sign-in, every 6 minutes. GitHub allows 60 unauthenticated requests an hour per address; each refresh makes at most 6. Times are in your time zone.
